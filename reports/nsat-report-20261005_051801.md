### AP-01: Direct Database Compromise & Credential Pivot
**Path Type:** Potential attack path | **Severity:** `CRITICAL` | **Confidence:** 0.85

```text
[1] External / LAN Reachable Network Interface (0.0.0.0)
[2] Vulnerable SQL Query Handler (D:\network-agent\tests\test_phase2.py:155)
[3] Exposed Database Credentials in Environment (test_phase2.py)
[4] Post-Compromise Database Access & Exfiltration
```
**Impact:** Remote unauthenticated attackers can execute arbitrary SQL queries and leverage leaked database credentials for complete database takeover.

**Defensive Recommendation:** Convert SQL queries to parameterized statements and rotate compromised credentials out of source repositories.

### AP-02: Authentication Credential Harvesting & Brute-Force Exposure
**Path Type:** Potential attack path | **Severity:** `HIGH` | **Confidence:** 0.80

```text
[1] Authentication Endpoint Without Rate Limiting
[2] Sensitive Token / OTP Transmitted in URL (D:\network-agent\tests\test_phase2.py)
[3] Telemetry, Proxy Logs, and Browser History Leakage
[4] Unthrottled Automated Credential Reuse / Replay
```
**Impact:** Authentication credentials and one-time passwords leak into server logs and can be replayed or brute-forced without throttling.

**Defensive Recommendation:** Transmit authentication credentials via secure POST request bodies and enforce IP rate limiting middleware.

### AP-03: Internal Runtime State Disclosure via Debug Endpoint & Stack Traces
**Path Type:** Potential attack path | **Severity:** `MEDIUM` | **Confidence:** 0.85

```text
[1] Unauthenticated Public Endpoint Access
```
